# DevFest Tarija 2026

## De On-Premises a la Nube: Construyendo una Infraestructura Híbrida Segura

Taller práctico sobre conectividad híbrida, seguridad de redes, Cloud Computing y automatización de redes con Python.

- **Evento:** GDG DevFest Tarija 2026
- **Fecha:** 28 de noviembre de 2026
- **Lugar:** UPDS Tarija
- **Instructor:** Reynaldo Lopez — Network & Security Engineer

## Objetivos del taller

- Comprender los fundamentos de una infraestructura híbrida.
- Conocer el funcionamiento de una VPN IPsec Site-to-Site.
- Comprender el rol del routing y las políticas de seguridad.
- Monitorear la conectividad y disponibilidad de servicios.
- Aplicar conceptos básicos de Network Automation con Python.

## Materiales del taller

| Archivo | Descripción |
|---|---|
| [Guía del participante](./DevFest_Lab_Guide.pdf) | Instrucciones y ejercicios prácticos |
| [Python Monitoring Script](./devfest_monitor.py) | Script de monitoreo de red y servicios HTTP |

Para descargar todos los materiales, seleccionar **Code → Download ZIP**.

## Requisitos

- Laptop con Windows, Linux o macOS.
- Python 3.10 o superior.
- Editor de texto o código.
- Conexión a Internet.

No se requieren cuentas de servicios cloud ni librerías adicionales de Python.

## Quick Start

1. Descargar los materiales del repositorio.
2. Abrir una terminal en la carpeta de descarga.
3. Verificar la instalación de Python:

       python --version

4. Ejecutar el script de monitoreo:

       python devfest_monitor.py

5. Seguir las actividades de la guía del participante.

En Linux o macOS, utilizar `python3` si es necesario.

## Tecnologías y conceptos

- Hybrid Cloud Networking
- Microsoft Azure
- IPsec Site-to-Site VPN
- Routing & Firewall Policies
- Network Security Groups (NSG)
- ICMP & HTTP Monitoring
- Python Network Automation
